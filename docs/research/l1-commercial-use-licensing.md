- 調査日: 2026-09-04
- 状態: **調査のみ**（コードは 1 行も書いていない。実装は未着手）
- 関連: [D-054](../decisions.md#d-054) / [C-071](../decisions.md#c-071) / [M-109](../measurements.md#m-109)
  / [D-035](../decisions.md#d-035)（初期リリースは現行素材のまま）/ [D-039](../decisions.md#d-039)（重みは MIT ではない）

⚠️ **これは法的助言ではない。** 一次ソースを読んで整理したものであり、
著作権法 30 条の 4 の解釈は本プロジェクトの読解にすぎない。

## 0. 結論

**現行モデルに残っている「出力の用途制限」は、教師の fine-tune に使われた
つくよみちゃんコーパスの 100 発話だけから来ている。**
6 言語 base の素材（LibriTTS-R / AISHELL-3 / CML-TTS / MOE-Speech）は
**帰属表示しか要求しない**（⚠️ **要求はする** — [C-072](../decisions.md#c-072) /
[D-055](../decisions.md#d-055) で必須帰属ブロックに入れた）。
したがって差し替えるべきは base ではなく fine-tune である。

| 論点 | 結論 |
|---|---|
| 「義務ゼロ（MIT / CC0）」は達成できるか | ❌ **できない**。base の LibriTTS-R (CC-BY-4.0) / AISHELL-3 (Apache-2.0) / CML-TTS (CC-BY-4.0) が帰属表示を要求する |
| 現実的なゴール | ✅ **「帰属表示のみ・出力制限なし・継承なし」= Apache-2.0 相当**（[D-054](../decisions.md#d-054)） |
| そのために要ること | (a) fine-tune の声を差し替える（100 発話）/ (b) 蒸留テキストから JSUT 6,472 行を外す |
| ⚠️ つくよみちゃんのままでゴールに届くか | ❌ **届かない**。出力の 4 禁止事項は**必ず利用規約として課す義務**があり、再配布者にコピーレフトする |
| 候補教師 `moe-speech-top-5speakers` | ❌ **推奨しない**（[M-109](../measurements.md#m-109)。音素表が別系統 + 実在の声優の声） |

## 2. つくよみちゃんコーパス — 一次ソースの原文

<https://tyc.rei-yumesaki.net/material/corpus/> を取得して本文を抽出した。

再現:

```bash
curl -sL -A "Mozilla/5.0" https://tyc.rei-yumesaki.net/material/corpus/ -o /tmp/tyc.html
# タグを落として「禁止」「クレジット」「コピーレフト」を含む行を見る
```

### 2.1 できること

> ■つくよみちゃんコーパスの声質が使える文章読み上げソフト、声質変換ソフト、歌声合成ソフト、
> その他の音声合成ソフト等を公開する。（音響モデルやAPIの状態での公開など、
> つくよみちゃんコーパスの声質を第三者が利用できるようにする行為全般を含む）

> ■有料・無料、広告収入の有無、ユーザーに対して商用利用や成人向け表現を許可するかどうかを問わず可。

### 2.2 ⚠️ 出力の禁止事項は **4 つ**（原文ママ）

> 【禁止事項】
> ■人を批判・攻撃すること。（「批判・攻撃」の定義は、つくよみちゃんキャラクターライセンスに準じます）
> ■特定の政治的立場・宗教・思想への賛同または反対を呼びかけること。
> ■刺激の強い表現をゾーニングなしで公開すること。
> ■他者に対して二次利用（素材としての利用）を許可する形で公開すること。

そしてこれを**課すことが義務**である:

> 音声合成ソフトの利用規約において、出力した音声を次の目的で使用することを禁止しない場合は、
> **事前にご相談ください。**

### 2.3 コピーレフトは明文

> 音声合成ソフト（「ソースコードの一部のみ」「音響モデルのみ」等の状態も含む）の改変・再配布を
> 許可する場合は、それを行うユーザーに対して「つくよみちゃんコーパスに由来する部分の取り扱いに
> ついてはつくよみちゃんコーパスの利用規約に従うこと」を義務付けてください。
> **この規定は、派生ソフトや再配布されたデータにもコピーレフトされます。**

### 2.4 ✅ エンドユーザーへのクレジットは義務ではない（本リポジトリの docs に書かれていない）

> 音声合成ソフトのユーザーに対して、ソフト使用時にクレジットを義務付けるかどうかは**あなたの自由**です。

> 上記の特例により、**音声合成ソフトから出力された音声にはクレジットの義務は発生しません**が、
> つくよみちゃんの他の素材は、それぞれの利用規約に基づいて使用されなければなりません。

**開発者（＝本リポジトリ）のクレジットは必須だが、下流のエンドユーザーに強制する必要はない。**
⚠️ ただし**改変・再配布する者**には 2.3 のコピーレフトが及ぶ。この 2 つは別の相手である。

### 2.5 ⚠️ リリース前の連絡が求められている

> そのため、リリース前に夢前黎にメールをお送りいただき、双方の合意の元で、
> クレジットの仕方について取り決めをさせていただければ幸いです。

「幸いです」なので文面上は依頼だが、その直前に理由が書かれている。
⚠️ **本リポジトリは v0.1.0〜v0.3.0 を既に配布済みで、この連絡を行ったかどうかを私は確認していない。**

### 2.6 参考: 提供元自身が 30 条の 4 で継承を外している

> 声優統計コーパスとJVSコーパスの音素バランス文（台本）は「CC BY-SA 4.0」のライセンスで
> 公開されていますが、つくよみちゃんコーパス Vol.1の制作・配布は「著作権法第三十条の四」に
> 基づくものであるため、「CC BY-SA 4.0」の継承（コピーレフト）を行う必要はありません。

本リポジトリが JSUT (CC-BY-SA-4.0) のテキストについて採っている立場（[D-035](../decisions.md#d-035)）と同じ形である。
**先例として使えるが、法的な保証ではない。**

### 2.7 ⚠️ リポジトリの記述との食い違い → [C-071](../decisions.md#c-071)

[`../../LICENSE-MODEL.md`](../../LICENSE-MODEL.md) §3.2 の表は一次ソースより**厳しい**:

| リポジトリの記述 | 一次ソース | 判定 |
|---|---|---|
| ❌ 個人・団体への攻撃・批判 | ■人を批判・攻撃すること | ✅ 一致 |
| ❌ 政治・宗教上の主張 | ■特定の政治的立場・宗教・思想への賛同または反対を呼びかけること | ✅ 一致 |
| ❌ **アダルト用途** | ■刺激の強い表現を**ゾーニングなしで**公開すること | ❌ **誤り**（§2.8） |
| ❌ 素材としての再配布 | ■他者に対して**二次利用（素材としての利用）を許可する形で**公開すること | ⚠️ ずれ（§2.8） |

### 2.8 何がどう違うのか

**アダルト用途は禁止されていない。ゾーニングしない公開が禁止されている。**

> つくよみちゃんプロジェクトは、表現の自由を尊重しています。
> **適切なゾーニングが実施されている限りにおいては、成人向け表現や残酷な表現についても
> 制限を設けておりません。**

「素材としての再配布」も、禁止されているのは**他者に二次利用を許可する形での公開**であって、
作品そのものの配布・販売ではない:

> ※鑑賞用の作品として配布・販売していただくことは問題ございません。

⚠️ ただし別の箇所に「■本品の声質を用いて合成された音声を、素材として配布・販売することも、
**原則的には**禁止です」ともある。**「原則的には」の含みを私は判断できない。**

## 3. MOE-Speech — 一次ソースの原文

<https://huggingface.co/spaces/litagin/moe-speech-license> は静的 Space なので
`index.html` を直接取れば本文が読める（ブラウザ表示は JS で "Refreshing" になる）。

再現:

```bash
curl -sL https://huggingface.co/spaces/litagin/moe-speech-license/raw/main/index.html -o /tmp/moe.html
```

### 3.1 ✅ モデルの公開は再配布ではない

> **再配布**: このデータセットの全体または一部を公開すること（その際に元のデータから
> 修正・改変した場合も含む）。ただし、**このデータセットを用いて機械学習モデルを作成した場合、
> そのモデルを公開することは再配布とみなしません。**

### 3.2 ✅ クレジットは不要 / 出力の用途制限も無い

> …このデータセットを利用することで得られた情報や機械学習モデルや成果物等については、
> 下記の再配布や改変にあたる場合を除き、自由に公開・共有することができ、
> **このデータセットを使用したことへの言及やクレジット表記は必要ありません。**

**出力音声の用途を制限する条項は無い**（禁止行為はデータセット自体の扱いに関するもの）。

### 3.3 ⚠️ ただし 2 つの縛りがある

> ただしこのデータセットへ言及する際には、識別名と声優やキャラクター名や出典元等との対応が
> 明らかにされるのを防ぐため、少数の識別名のみを使用しその特徴が再現されているような
> 共有物については、**使用した識別名を公開しないようにしてください。**

> 【禁止行為】このデータセットの特定の識別名のデータを**享受目的**で利用すること。

### 3.4 ⚠️ 本リポジトリの帰属表示ブロックは過剰帰属 → **2026-09-09 に直した**

[`../../NOTICE.md`](../../NOTICE.md) と [`../../LICENSE-MODEL.md`](../../LICENSE-MODEL.md) §3.1 の
「1 行でも欠けると違反」と書かれた帰属ブロックに MOE-Speech の行が入っているが、
**MOE-Speech のライセンスは帰属表示を要求していない**（§3.2）。
違反ではない（過剰に書く分には問題ない）が、「欠けると違反」という説明は
この 1 行については正確でない。

✅ **その後、逆方向の欠落も見つかった** — **帰属を要求する 3 素材
（LibriTTS-R / CML-TTS の CC-BY-4.0、AISHELL-3 の Apache-2.0）が抜けていた**。
[C-072](../decisions.md#c-072) で訂正し、[D-055](../decisions.md#d-055) で
**(A) 必須 / (B) 任意**に分けた。

## 4. 候補教師の実測

数値と再現コマンドは [M-109](../measurements.md#m-109) にある。要点だけ:

`ayousanz/piper-plus-moe-speech-top-5speakers` は
`inter_channels=192` / `hop_length=256` / `sample_rate=22050` が現行教師と一致するので
**c-line の潜在インターフェースは移植できる**。しかし:

- `num_symbols=58`（現行 173）→ **`csrc/g2p_table.json` と `vocab.py` の `TEACHER_TO_STUDENT` を作り直し**
- `upsample_rates=(8,8,4)` / `upsample_kernel_sizes=(16,16,8)` = **標準 HiFi-GAN**（MB-iSTFT ではない）
- prosody / zero-shot 無し
- ⚠️ 中身は**実在の声優が演じたゲームキャラクターの声**。データセットのライセンスでは
  放棄できない**パブリシティ権・人格権のリスク**が残る

**形式上のライセンスは現行より軽いのに、商用製品としては現行より危ない。**

## 8. 次の判断

1. **声をどうするか** — 外部の声優への依頼（進行中・未確定）/ Common Voice の CC0 音声を検証する / 当面は つくよみちゃんのまま
2. **JSUT を外すか** — 声と独立に進められる。外せば継承リスクが消える
3. **[`../../LICENSE-MODEL.md`](../../LICENSE-MODEL.md) §3.2 を一次ソースに合わせて直すか**
   （§2.7 / [C-071](../decisions.md#c-071)）。⚠️ **制限を緩める方向の変更**なので、
   配布済みの v0.1.0〜v0.3.0 の表示とも食い違うことになる
4. **§2.5 の事前連絡**を行うか
